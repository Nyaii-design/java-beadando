A projektről

Az alkalmazás a Java alkalmazások tantárgy előadásának beadandójaként készült, Java 25 és Spring Boot keretrendszer felhasználásával. A SOAP menü a Magyar Nemzeti Bank webszolgáltatását használja, a Forex menük pedig az Oanda v20 REST API-n keresztül kommunikálnak egy demószámlával.

  • Java 25, Spring Boot, Thymeleaf
  • SOAP kliens (JAX-WS) + Chart.js grafikon
  • Oanda v20 API
  • Bootswatch Flatly reszponzív téma
